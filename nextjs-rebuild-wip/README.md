# Parked: Next.js rebuild (not the live site)

This folder holds an early-stage Next.js/TypeScript scaffold — design tokens,
data model, a mega-menu, a routing skeleton, and a simplified homepage. It
was a first attempt at the full production rebuild `README.md` (at the repo
root) describes, but it does **not** match the fidelity of the actual design
and is not what's live. It's kept here in case the rebuild is picked back up
later; it isn't wired into anything and doesn't need to be touched.

**The live site is the design bundle at the repo root** —
`CryptoSlotGuide.dc.html` + `support.js` + `image-slot.js` + `assets/`.

To resume this rebuild: `cd nextjs-rebuild-wip && npm install && npm run dev`.
